-- SET UP: MAKE IT LEGAL AND REAL ------------------------

[ ] Choose your structure
[ ] Get your EIN
[ ] Check licenses and permits
[ ] Open a business bank account
[ ] Set up bookkeeping before the first transaction
[ ] Get insured
[ ] Set aside tax money from the first payment

-- BUILD: MAKE IT DELIVERABLE ----------------------------

[ ] Build the smallest deliverable version
[ ] Write down how you deliver it
[ ] Get a simple web presence up
[ ] Set up payments and contracts
[ ] Pick a deliberately short tool stack

[ ] Ask every customer for a referral and a testimonial
